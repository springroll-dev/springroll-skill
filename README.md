# SpringRoll skill

Reusable skill for the complete SpringRoll MCP control plane.

Includes the versioned app-record SDK and editable Next.js, Node,
Docker, Redis and Cloudflare D1 templates. No SpringRoll source
repository access is required. See the skill's app-record reference.

```bash
npx skills add springroll-dev/springroll-skill --skill springroll
```

## This repository is generated

Do not edit these files here. They are published automatically from
the SpringRoll application repository, which is the source of truth,
and any change made directly to this repository is overwritten by the
next publish.

The skill's prose is governed by that repository's copy gate, which is
the reason authorship lives there: an agent reads a skill verbatim and
repeats its sentences to a person, so the document answers to the same
rules as any page the product renders.

To change the skill, change it in the application repository and merge
to `main`. Publication follows automatically.
